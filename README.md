# 🚀 AI-Powered Interview Preparation Platform 
A full-stack AI-powered interview preparation platform designed to helps users prepare for technical interviews with personalized questions based on their job role and experience level. Using the Gemini API, it generates interview questions, answers, and detailed explanations to make learning easier and more effective.
***
## 📌Features
### 🔐 JWT Authentication
* Secure user registration and login
* Protected routes and personalized dashboards
  dashboards

### 👨‍💻 Role-Based Interview Sessions
* Questions generated according to selected role and experience level
* Customized preparation for different career paths

### 🤖 AI-Powered Question Generation
* Uses Gemini API to create high-quality interview questions
* Generates detailed answers and technical insights

### 💡 Dynamic AI Explanations
* Request additional explanations for any topic
* Simplifies complex concepts into easy-to-understand language

### 📌 Pin Important Questions
* Bookmark key questions for quick revision
* Build your personalized interview preparation list
***
## 🛠️ Tech Stack
### Frontend
* React.js
* Tailwind CSS
* React Router DOM
* Axios
### Backend
* Node.js
* Express.js
* JWT for Authentication
* REST APIs
* MongoDB(Mongoose)
* bycryptjs for password hashing
***
# 🔧 Environment Variables
 Create a .env file in the backend directory and add:
```env
PORT=8000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secure_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
```
